### Problématique
Analyser 50+ projets (task_name, assigned_to, start_date, days_required, end_data, progress) pour identifier les retards et le taux d'avancement.
### Résultats
- Durée moyenne : 18 jours
- Tâches 100% : Market Research, Campaign Analysis, UI Design
- Tâches 0% : Social Media Planning, Quality Assurance = ALERTE
- Avancement global à suivre par assigner_to
  ### Recommandations
  1. Suivi hebdo pour les Progress <0.5
  2. Revoir estimation des jours
  3. Prioriser les tâches à 0%
